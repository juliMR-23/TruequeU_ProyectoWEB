# 🔄 TruequeU - Frontend
## Equipo 9: Julián Marín, Maria José Sosa
 
Este repositorio cubre toda la **interfaz de usuario** para TruequeU, plataforma de intercambio de artículos diseñada para la comunidad de la Universidad EIA. El objetivo es facilitar el intercambio entre estudiantes, promoviendo la economía circular.
 
## Estructura del proyecto
* Framework: React (Vite) - Estructura ágil y moderna
* Estilo: Tailwind CSS + React Icons - Diseño intuitivo y responsive, siguiendo la línea visual de la EIA
* Navegación: React Router Dom - Gestión de rutas e interacción sin recargas
 
## Características Principales
* Layout adaptativo (Split-screen en desktop, apilado en móvil) con balance visual centrado
* Formularios con validación de errores dinámica por campo y prevención de envíos duplicados
* Arquitectura basada en componentes reutilizables y hooks para la lógica de sesión
 
## Instalación de dependencias
   ```bash
   npm install vite@latest
   npm install react-router-dom
   npm install tailwindcss @tailwindcss/vite
```
